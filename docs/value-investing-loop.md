# 价值投资工作流使用指南

> 平台的完整闭环地图：从看市场到复盘，每一步在哪个页面、点什么按钮。
> 核心理念：**论点即持仓**——持有 = 买入时记录的假设尚未被证伪。

## 全流程一览

```
市场层          选股层            决策层                持有层(自动化)           卖出层         复盘层
─────────      ─────────        ──────────           ──────────────          ─────────      ─────────
温度计    →    排雷雷达     →   买入体检          →   17:35 论点重估 job   →   卖出体检   →   决策日志
```

## 按场景找功能

### 我想看现在市场贵不贵、该留几成仓
**市场温度页（/indices）温度计 Tab**：五档温度（极冷→过热）+ 股债性价比 ERP 与历史分位 +
建议整体仓位水位；点击展开 5 年 ERP 曲线与水位策略回测结论。"指数水位"Tab 看主要指数
估值分位，"破净率择时"Tab 看阶段性底部参考区；持仓体检页顶部留有一行精简温度条
（整条深链直达温度计 Tab）。数据每日 17:40 自动快照。

### 我有一只候选股，怎么系统排查
1. **财务分析页**：五法估值（DCF 敏感性矩阵 + 五法综合公允区间条 + **市场隐含预期 Reverse DCF**——当前价格在定价多高的永续增长，与你的假设对照）、质量分、护城河；
2. **排雷**：买入体检内含 Z/M/红旗明细；持仓体检页"排雷雷达"可查全市场 Z 扫描名单；
3. **对比**：财务页"对比 →"把候选加入 `/compare`，与 2~3 只同行并排 13 维（质量/护城河/成长/五法 upside/资本配置，最优值高亮）；
4. **研究笔记**：财务页"笔记 →"，年报阅读记录沉淀在 `/notes`。

### 决定买了：买多少、怎么买
- **财务页"论点 →"** 进入登记（或自动建组合页腿上"论点"一键带入成本/股数）；
- 登记框自动显示**仓位建议卡**：档位（强/中/弱）+ 建议仓位区间 + 半凯利参考 +
  **三档建仓计划**（现价/-8%/-16%）；
- 填假设条件前点**"校准阈值（16 季回测）"**——看你的条件历史上会误触发几次；
- 登记时自动抓快照：质量分、五法 upside、**当时市场温度**（复盘时对照"我是追高还是逆向"）。

### 持有期间（全部自动化，不用盯）
- **17:35 job**：持仓股发新财报 → 自动重估（质量/估值/条件）→ 结论
  pass/review/sell_signal 落库并推送预警中心；
- **估值带到价**：现价/PE 进入你的目标卖出带 → 事件推送；
- **每日排雷精查**：Z+M+红旗三查，高危 → 排雷告警；
- 全部事件汇聚在**预警中心（/alerts）统一收件箱**，论点事件可标已读。

### 考虑卖出时
**持仓体检 → 点论点卡片 → "卖出体检"按钮**，四区报告：
- A 论点体检：每条假设现值 vs 阈值（破没破）；
- B 估值到位：现值 vs 目标卖出带 + 安全边际消耗了多少；
- C 基本面变化：质量分 vs 买入时、新增红旗；
- D 卖出三问：逻辑证伪？估值到位？有更优替代（去 /compare 拉对照）？
之后**记录决策**（持有/减仓/清仓 + 理由），关闭时选四种归因之一。
建仓执行：详情页"建仓执行"表逐档标记成交，跟踪已投比例与均价。

### 定期复盘
- 持仓体检页**复盘区**：按关闭原因统计盈亏（论点破位止损 vs 估值到位止盈
  各赚多少）+ 最近决策流水；**已关闭表的"关闭后"列**——卖了对不对的硬反馈
  （+x%=卖飞 / -x%=卖对，汇总"卖飞 y/z"）；>30 天未复盘有横幅提醒；
- **组合体检**折叠区：行业集中度（>40% 预警）、持仓相关性 + 有效独立仓位数、
  组合加权 PE/PB、**压力测试**（2018 贸易战/2020 疫情/2021-24 长熊/2024 冲击
  四个历史极端窗下本组合的回撤与最大拖累持仓）；
- **股息日历**：未来 12 月分红排期与预期收入流；
- **管理层与资本配置**（论点详情内）：分红连续性/分红率/ROIC/筹码 + 近 24 月
  回购与增减持行为摘要。
- **研究管道**折叠区：持仓>已关闭>已体检待决策⚠>研究中>观察——"待决策"层
  就是研究烂尾的堵点，定期清空。
- **温度计 Tab 展开**（市场温度页 /indices）：16 年 ERP 曲线 + **水位策略回测结论**
  （实测年化 4.8%/回撤 32% vs 买入持有 2.5%/47%——建议仓位经受过自身历史检验）。

## 口径速记（防误读）

- ROE 一律 **TTM**（当期累计+上年年报−去年同期）；同比基期=**去年同一报告期**；
- 估值内在值多为公司总值，跨口径比较一律用 **upside 比率**（内在/市值−1）；
- 温度计历史分位为**运行分位**（截至当日序列内），无未来数据；
- DCF 结论看敏感性**区间**，不看单点；行业资金流源只有当日快照，断档无法回填。
