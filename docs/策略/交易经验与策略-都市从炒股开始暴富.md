# 《都市：从炒股开始暴富》交易经验与策略提炼

> **来源**：小说《都市：从炒股开始暴富》（全 1018 章）
> **主角**：李成刚（普通散户 → 游资 → 价值投资者）
> **提取范围**：贯穿全书 1018 章，按"心态 → 仓位 → 选股 → 买卖 → 止损止盈 → 龙头板块 → 技术量能 → 消息情绪 → 复盘心法 → 市场规律"十大类归类
> **声明**：本笔记为小说情节提炼，仅供学习参考，实盘需结合自身风险承受能力谨慎运用

## 一、交易心态（心态第一，技术第二）

### 1. 心态决定技术
- **心态第一，技术第二**：股市博弈本质是心理博弈，没有良好心态就没有技术可言。贪婪和恐惧会让判断产生扭曲。再牛的技术也会败给心态——你不是输给了市场，而是输给了自己（第197、293、360、537、1018章）。
- **心如止水**：经多年复盘反思才能做到——不被盘中突然急速拉升吸引，也不因连续下跌后的大幅跳水而恐惧（第220章）。
- **情绪是市场里最不需要的东西**：能将情绪抛掉、冷静客观看市场运行，是成功者必经一步（第537章）。

### 2. 贪婪与恐惧
- **财不入急门**：炒股不能急于扳回损失。割肉后立即换股期待弥补亏损，大概率再次亏损（第198章）。
- **贪婪的多种表现**：除想多赚钱外，还表现为想抓住每一次机会、频繁换股、不肯让资金休息（第592章）。
- **"新人死于追高，老手死于抄底"**：老股民不追高了改抄底，但没耐心会在非底部买入，真底来时被吓割肉（第534章）。
- **别人贪婪我恐惧，别人恐惧我贪婪**：众人一致看好时要提防黑天鹅（第166章）。

### 3. 成本与心态
- **成本决定心态**：盈利丰厚时心态好，被套重仓时患得患失；轻仓持股心态最好，涨跌都坦然（第201、215章）。
- **屁股决定脑袋**：满仓一只股票后，一旦下跌就会自我幻想"这是洗盘""这么好的股票能跌到哪"，开始自欺欺人（第215、208章）。
- **掩耳盗铃**：不看账户但心里记成本、算盈亏，是典型掩耳盗铃；真正的心如止水是不算成本只看走势（第551章）。

### 4. 重要心法
- **炒股先想能承受多大亏损，而非想赚多少**：只有这样才能心态平和、承受风险（第184章）。
- **炒股不是上班，没有稳定收益**：不能因一次盈利就理所当然认为每天都会同样盈利（第189章）。
- **股市中先活下来，才是最重要的**——只有活下来才能谈赚钱（第229章）。
- **宁愿错过也不做错**：短线精髓在于积少成多，回撤可以有，但绝不能大幅回撤（第245章）。
- **只赚自己能看懂的钱**：看不懂时最好的办法是先撤出来观察（第447、544章）。
- **耐心是赚大钱的前提**：没有耐心的散户只能赚小钱，好价格都是等来的，时机通常只有几分钟（第358章）。
- **每临大事有静气**：不能让情绪主导交易，要有自己的逻辑并在走势未大变前坚持（第557章）。

## 二、仓位管理（永不满仓）

### 1. 核心铁律
- **永不满仓**：满仓就是不给自己留后路，是交易最大忌讳。满仓后心态立刻患得患失，满仓被套后只能"卧倒装死"（第351、573章）。
- **分批买、分批卖**——铁一般的纪律。给自己多犯几次错误、修正交易的机会；哪怕做T失败当天也必须割肉出来（第192、178章）。
- **单只股票最多半仓**（看好最多五成），做到进可攻退可守（第178、215章）。
- **保留备用金**：像战场上的备用部队，关键时刻能扭转乾坤（第174章）。

### 2. 仓位与心态、风险
- **仓位代表一个人的贪婪**：仓位越重=越贪婪。仓位重则心态乱，一跌就慌，分析失准（第790章）。
- **仓位轻=安全垫=分析冷静**：持股仓位只占本金28%时，"哪怕跌停再跌停我也有安全垫"，盘面波动不会影响判断（第790章）。
- **控制仓位即可控制风险**：只要不贪婪，控制仓位就能控制风险；十次车祸九次快——投资不能心急（第392、590章）。
- **不论在市场摸爬滚打多少年，不控制仓位永远不能成功**：举例有人牛市赚一个亿，重仓融资中车全部赔光（第790章）。

### 3. 仓位结构与方法
- **牛市仓位结构示例**：六成长线捂股，三成短线激进，一成备用（第174章）。
- **3136 金字塔式买入法**（左侧分批建仓，第791章）：
  - 第一个"3"：计划用 **1/3 总仓位** 操作这只股票
  - "1"：首次试探建仓 = 该 1/3 仓位的 **1 成**（仓底）
  - "3"：第二次买入 = 该 1/3 仓位的 **3 成**
  - "6"：第三次买入 = 该 1/3 仓位的 **最后 6 成**
  - 效果：越跌越买呈正金字塔，有效拉低持股成本，10% 止损大概率打不到。
- **金字塔式补仓要正金字塔**：多数股民做反了——开始就重仓，跌深后无钱可补，起不到拉低成本作用（第562章）。
- **半仓被套的自救**：手里还有资金，当天买入当天卖出做T；若一路下跌，等跌到前期密集交易平台有反弹迹象时再买入半仓，反弹后全卖只留100股底仓（第215章）。
- **大资金组合式投资**：资金越大越要分散，追求组合式投资和个股流动性（方便进出）。科技/金融=攻击性板块，白酒/食品/医药=防御性板块，进可攻退可守（第407、411章）。

### 4. 资金量与操作风格
- **资金不能过度分散**：十几万资金量最好持股1-2只。50万买25只股票看似分散风险，实则股灾来时全跌停（第178章）。
- **小资金也要严格分仓**：好的习惯从一开始培养（第234章）。
- **资金量大小决定操作风格**：钱少灵活激进、船小好调头；钱多转向大盘蓝筹，注重业绩稳定与流动性。3000万买日成交1亿的小盘股，丢出去就不是做T而是砸盘（第928章）。
- **借钱/举债炒股是大忌**：心里有压力后，会在没机会时千方百计找"假机会"冒险一搏（第538章）。

## 三、选股思路

### 1. 选股总则
- **做熟不做生**：选自己熟悉的股票操作。长期跟踪一只股票，看完整上涨-下跌-调整规律后会有朦胧感觉（第552章）。
- **强者恒强，股性活跃弹性大**。
- **从生活中发现好公司**：日常经常看见其产品、销量大、有独特优势的，就是好公司最简单的判断方法（第156章）。
- **炒预期，不炒现实**：龙头公司份额大但缺乏预期，小公司反而因低基数涨幅更猛（如赤峰黄金 vs 山东黄金）（第236章）。

### 2. 牛熊选股逻辑
- **牛市重势，熊市重质**：牛市炒题材/故事/新兴概念，熊市炒业绩稳定确定的股票。交易模式必须随牛熊切换而改变（第169、177、924章）。
- **小盘股优先（牛市）**：几千万-两亿股本，主力资金不需很多、便于控制（第174、177章）。
- **大资金选股逻辑**：业绩稳定、流动性好、分红豪爽、不会暴雷造假（第929章）。
- **价值投资选股**：业务稳定经营、分红能力强的老牌大公司（中石化、格力、茅台、恒瑞医药）（第958章）。
- **价格是展现股票价值的因素**：中石化19元不是好股票，跌到3-4元高股息立刻变好股票（第928章）。

### 3. 行业与主线
- **抓住主线**：每一轮行情都有一条主线，只有主线股票才涨得最多。创业板主线是科技股（第563章）。
- **牛市旗手券商先行**：大金融板块不表现，牛市不会到来（第192、177章）。
- **金融是牛市隐藏主线**：牛市的底色和发动机往往是金融板块（券商、保险、银行）（第695章）。
- **医药股是真正的硬性消费**：生病必须吃药，不花不行（第154章）。
- **茅台特例**：具金融属性+面子属性（产量稀少、可拍卖、招待有面子）（第155章）。

### 4. 避坑选股
- **讲故事的公司要远离**：乐视网这类会讲故事的公司，风口上能上天，风停了哪里来回哪去（第209章）。
- **不炒消息股/重组股**：当大多数股民都知道的消息，往往就是主力开始出货（第386-387章）。
- **新牛市不碰上一轮妖股**：每一轮牛市都有新龙头、新主线（第688-689章）。
- **板块内股票少于10只没意义**：起不到领头板块效果，难吸引大量资金；最好20只左右且含中盘权重股（第909章）。

## 四、买卖点

### 1. 买入原则
- **买入要有逻辑支撑**：追高前必须熟悉股票，有深层逻辑（第175章）。
- **看长做短，长短结合**：长线捂好股不动，短线抓启动拉升的个股（第174章）。
- **下跌买入、主动买套**：看好一只股票，采用下跌分批买入（3136法）控成本（第791章）。
- **突破后回踩确认**：股票突破前期高点后必须回踩，踩住才算是有效支撑，是买入机会（第205章）。
- **强势股第一次回踩10日线是短线进场好机会**（第240章）。
- **10日均线买点**：走出跳空缺口后，股价第一次跌破5日均线触碰10日均线时，10日均线位置是短线买点（第537章）。
- **二次探底/双底确认后买入**：不出现二次探底走势绝对不加仓（第955章）。

### 2. 卖出原则
- **加速阶段才卖**：上涨股票不出现跳空缺口（无效加速）就不卖，让利润奔跑；出现跳空缺口（有效加速）才是卖出信号（第176-177章）。
- **越涨越卖，分批卖出**：股神也不可能卖到最高点。知足常乐（第191章）。
- **止盈位置预先定好**：到位置毫不犹豫落袋为安，哪怕随后再涨也不追（第190章）。
- **卖出后别后悔**：只要卖出理由出现就果断卖，不要想着卖在最高点（第532章）。
- **短线止盈纪律**：浮盈剩3%就止盈离场（第932章）。

### 3. 集合竞价与挂单技巧
- **集合竞价判真假单**：9:15-9:20可撤单（多为假托单）；9:24-9:25才是真实竞价；买2档口出现报价单则买1为真单（第175、199、543章）。
- **价格优先时间优先**：买入时价格略挂高弥补时间劣势，卖出时往低挂以确保成交；第一时间成交把买单价格挂高/卖单价格挂低（第175、214、536章）。
- **集合竞价阶段卖股**：要在9:24看价往低挂卖出（第608章）。

### 4. 盘中操作技巧
- **盘中急速拉升通常有两次**：第一次拉升后回落整理，散户忍不住卖出，然后主力二次拉升。卖在二次拉升高点（第241章）。
- **逆势上涨的股票第二天往往低开**：大盘下跌时别买逆势上涨股（第240章）。
- **别在盘中轻易决定**：临近收盘（如2:50）再做割肉决定，因为盘中主力会做出种种走势恐吓散户（第351章）。
- **盘中少做决定**：没有复盘习惯又喜欢盘中做决定，往往弄巧成拙；功夫在盘外（第549章）。
- **"神奇的两点半"**：尾盘两点后常出现关键走势（跳水或拉升）（第560章）。
- **看盘的正确方法**：看盘不是看盘中价格波动，而是观察今天会收出什么样的K线、换手率和成交量变化（第574章）。

### 5. 做T 原则
- **做T原则比短线更坚决**：抓住盘中2%利润就够。当天买当天卖，底仓保留（第195章）。
- **长线底仓千万别拿来做T**：没有娴熟盘感会越做成本越高（第243章）。
- **做T的股票若看错，收盘前不论盈亏都要坚决卖掉**（第443章）。
- **下跌途中做T/高抛低吸意义不大**：不如直接割肉等底部再介入（第939章）。

## 五、止损止盈

### 1. 止损纪律
- **无条件 7% 止损**；3% 也可认错止损（早期章节）。
- **设定止损线（如10%）坚决执行**：买入后走势脱离预设范围，要做的是果断割肉止损，而不是补仓（第608章）。
- **短线看错就要认**：这市场只要钱不要命。看错及时止损，保护资金不大回撤，是短线精髓（第178章）。
- **浅套果断斩仓好于做T解套**：做T偶尔成功，但大概率越T亏损越多（第608章）。
- **买错方向=上错车**：买车票去京市结果车往广市开，应及时下车损失路费，而不是补票越陷越深（第608章）。
- **波段走势一旦跌破前期支撑位，果断割肉，不能心存幻想，只有活着才有机会**（第914章）。

### 2. 止盈艺术
- **截断亏损，让盈利奔跑**：投资最重要的是控制风险（早期章节）。
- **越涨越卖，分批卖出**（第191章）。
- **不贪才是最大的贪婪**：短线精髓在积少成多（第192章）。
- **见好就收**：火中取栗博一下，见好就收即可（第533章）。
- **止盈看成交量和位置**：未出现高位放量滞涨前不轻易止盈（第789章）。

### 3. 复利与回撤
- **复利思维**：雪球从小慢慢滚大，不贪才是最大的贪婪（第234章）。
- **满仓交易1%的亏损，需要盈利2%才能赚回**：A股跌速远超涨速（涨停板特点+牛短熊长）（第178章）。
- **一次大幅回撤会让几次成功的利润全部回吐**：短线精髓在于积少成多，回撤可以有，但绝不能大幅回撤（第245章）。

### 4. 隔夜委托与黑天鹅
- **隔夜委托跑路**：遇黑天鹅，夜市委托（9点后可挂单）越早排队越靠前，第二天9:15送交易所，跌停板上争取跑出（第446章）。
- **危机=危险中有机会**：三聚氰胺事件中伊利被错杀，是买入机会（第166章）。

## 六、龙头与板块

### 1. 龙头战法
- **龙头强则板块强**：一个板块能走多高走多远，要看龙头到底有多强（第102章）。
- **龙头就是旗帜**：龙头股不断上涨带动板块跟涨，龙头跳水则带崩整个板块（第349章）。
- **龙头判断方法**：板块发动时，第一个最早封涨停板、涨幅远超同类的是龙头（第425章）。
- **龙头股≠行业龙头**：市场炒作的"龙头"是资金接力打出来的，不是基本面行业第一（第688章）。
- **热点扩散选股**：板块龙头连续涨停后，要从同板块找主营业务最相关、盘子较小、有预期的股票（第235-236章）。

### 2. 板块轮动
- **大盘搭台，小盘唱戏（跷跷板效应）**：权重股和创业板轮动，强势板块领涨几天后调整，弱势板块接力（第218章）。
- **资金像水往低处流**：牛市领头板块被爆炒后，新股民发现贵了就买便宜的主板股（第179章）。
- **板块轮动=打仗配合**：有主攻主力部队、佯攻二线部队、骚扰游击队；大盘每次上涨都是几个关联板块形成合力（第1010章）。
- **补涨信号**：弱股补涨往往是行情末端；前期强势股补跌常是见底信号（第524章）。
- **权重搭台、小票唱戏**：黄线（小盘）在上、黑线（权重）在下同步上涨是健康走势（第570章）。

### 3. 主力操盘手法
- **养套杀三部曲**：养（让散户失去警惕）→套（小幅亏损不割肉）→杀（低开低走5-7%再小反弹安慰后突然跳水猛杀）（第338章）。
- **水果贩子出货理论**：高位出够本钱后砸盘，一路卖利润，怎么卖都是赚（第244章）。
- **涨停板出货法（最损手法）**：前几个涨停反复开板震荡吸引注意，培养散户"明天还会涨"的固定思维，散户贪婪冲入时，主力利用封单撤单+同价再报（利用时间优先规则）在涨停板神不知鬼不觉出货（第244章）。
- **关门打狗出货**：高位连续拉升/横盘只能出部分筹码→跳楼大甩卖→一字跌停不开板→打开跌停板接住筹码继续出货→小反弹→小双头（二次欺骗请君入瓮）（第1009章）。
- **真假砸盘的辨别**：真砸盘时上方卖单很少，突然出现大卖单砸低好几个点；假砸盘（压盘）时上方挂着巨量卖单，意在恐吓散户低价割肉（第384章）。
- **真假涨停板**：集合竞价阶段，若买2位置还有买单堆积，则是真涨停板（第395章）。

## 七、量价、换手率与筹码（全书最核心，"做不了假"的指标）

> 作者反复强调：**成交量和换手率做不了假**，是最核心、最可靠的判断依据（第47章）。K线可被主力画，但量骗不了人。

### 1. 量比（作者最重视的指标之一，第23章）
- **数值判读**：量比=1 普通；<1 明显缩量；>2 略微放量；>5 开始放量。
- **量在价先**：股价**向上**+量比持续放大+买盘不断 = 主力主动进攻（买点）；股价**向下**+量比放大 = 砸盘出货（卖点/避险）。
- **回调买入安全条件**：连续上涨后回调，量比<1 时逢低进入较安全（第316章）。
- **连续下跌后量比仅0.5左右** = 上方抛压已消耗殆尽，下跌空间有限。
- **早盘（9:30-10:30）高位回落个股，量比0.8左右且回到前期大/中阳线附近** = 可考虑介入。
- **陷阱**：单看量比买入 = 和无脑看 MACD 金叉一样蠢，必须结合 K线位置和前期 K线组合。

### 2. 成交量与量价关系
- **量在价先**：量能像汽车汽油，没有持续放大的成交量走不远（第213章）。
- **健康洗盘**：上涨放量+换手率变大；下跌缩量+换手率变小 = 主力没出货，是洗盘。
- **缩量拉升（解放前期套牢盘）** = 主力对现价不满足，接下来必有大行情（可能翻倍至翻十倍）。
- **放量拉升**往往后面还有更猛烈的放量洗盘。
- **缩量上涨还要涨，缩量下跌还要跌**：缩量上涨散户锁仓配合主力出货；缩量下跌主力慢慢出货（第914、1009章）。
- **缩量新高=假突破真出货**（第141章）：高位横盘时上涨缩量、下跌放量 = 主力悄悄托盘出货；高开创新高收阴但量没超过前期十字星 = 缩量新高，诱多陷阱。
- **倍量需警惕**（第190章）：倍量≠会连续大涨。受消息刺激的倍量第二天往往萎缩，主力借利好出货；**不能头脑发热冲进去**，要观察是否**连续几天**放量，只一天的不介入。
- **天量见天价，地量见地价**：高位放天量=见顶；连续下跌后成交额创出新低=底部信号（但需随后反弹确认）。
- **看成交量不要只看红绿柱高低**：分时图红绿柱是"成交额（钱）"不是"成交量（手数）"，只比柱高会误判（第788章）。
- **量价背离=果断离场**（第641章）：连续缩量上涨（换手率降低）= 主力已停止对敲拉升、在偷偷出货 → 哪怕涨得再好也要走，一旦背离出现高位大阴破位的几率极大。

### 3. 换手率（做不了假，核心）
- **判断主力收集筹码**：涨幅不足1%但换手率达7% = 主力高度控盘、暗中收集筹码+倒仓压价（散户筹码已不多，主力稍买就飙，所以压着买）（第176章）。
- **换手率不足40%无法一天出货**：判断主力出货的重要依据。
- **加速建仓**（利好刺激）换手率可达30%-40%；换手率稳定在20%左右的换手板 = 量价齐升健康走势。
- **洗盘vs出货**：洗盘=换手率走低、缩量、震荡后向上；出货=高位放量、换手率明显走低+缩量高位震荡（第641章）。
- **真正下跌的股票每天换手率很低（5%以下）**，轻易跌破支撑位；洗盘时大阴线换手率却有10%甚至更高（第445章）。
- **换手率维持在10%多且非常稳**（高位）= 主力悄悄托盘出货。

### 4. 筹码、套牢盘与获利盘（作者最核心的分析框架）

> 本书中"筹码"不是指筹码分布软件指标，而是通过量价、换手率、K线位置**推断主力筹码行为**。所有K线都是为"消化筹码"服务的。

**【套牢盘消化——主力拉升前必做】（第175、190章）**
- 主力不会"好心"解救套牢盘。一旦高开/放量解放前期套牢盘 = 目的是拉升前的换手。
- **消化套牢盘的标准手法=低开大幅震荡**（不拉高消化）：因为拉高到解套位后套牢盘反而不卖（等赚更多），只有剧烈震荡把他们再套回去一次，第二次解放时才会卖出。
- **第一次解放套牢盘**：放量拉升解放→顺势冲高15%→倒仓放出巨量大阴线跌下，但**不跌破突破平台**。
- **买点**：一旦**放量突破并站上前高套牢区**，说明主力决心拉升。
- **解放历史套牢盘的意义**：主力花大力气解放6124/5178套牢盘，绝不会只为不到一两百点空间 → 解放历史套牢盘 = 后市还有大行情。

**【平均成本抬升逻辑】（第176、258章）**
- 主力拉升后到密集交易平台会**横盘几天、换手率放大、再上一个台阶**——本质是把前期筹码和获利盘对倒给新进场者，把市场平均成本抬到该区间，之后拉升才轻松。
- **买点**：缩量开始拉升时进场（说明洗盘完成、平均成本已抬高）。

**【获利盘消化】**
- 连续大涨后获利盘堆积过多，主力必洗盘调整蓄势，否则拉升抛压太大。
- 突破前高=要解放套牢盘+换手，**必须放量**；不放量、不温和上升 = 假突破。

**【出货 vs 洗盘的筹码判断】（第141章）**
- 底部/筹码不够 → 反复洗盘直到拿够；已启动拉升 → 只急跌一波洗盘，不会反复。
- **反复横盘震荡、日K线上上下下** = 横盘**出货**不是洗盘。
- 高位横盘震荡出掉大部分筹码后，主力已盈利，后期一路缩量阴跌，"卖掉的都是利润"（水果贩子理论）。

**【判断主力是否收集够筹码】**
- 温和放量+慢慢向上推升 = 主力在收集筹码。
- 底部长期震荡两年 = 主力完成底部搜集。
- 盘中吃入推高→砸下→另一账户下方承接 = 倒仓（K线看不出，但**换手率暴露**）。

## 十一、技术指标与K线形态详解

> **作者对指标的总态度**（贯穿全书）：任何单一指标都不可作为买卖依据。MACD/KDJ 这类"计算型指标"**滞后、只能"显示正确"不能据此操作**；真正可靠的是 K线形态 + 量价换手 + 筹码位置 + 缺口加速信号。必须把所有信号**联合起来看**，只看一方面会觉得技术不可靠。

### 1. MACD（第54-56章：核心否定章节）
- **金叉/死叉**：黄线上穿白线=金叉（看涨），白线下穿黄线=死叉（看跌）。原理≈量放大+均价升高→金叉（即1+1=2）。
- **致命陷阱**：当天出金叉追进去，当天股价下跌金叉走平，第二天一个跌停立刻变死叉。**指标是滞后的**，随股价随时变，"当时看绝对正确，事后看坑死人"。
- **本质比喻**：MACD 像"宾馆墙上的表"——显示的时间永远正确，但你不能拿它决定现在该做什么。**绝不能单纯看 MACD 金叉买入、死叉卖出**。
- **牛市 vs 熊市**：牛市用指标能蒙对（因为本来就在涨）；熊市指标可在底部**无限钝化、无限背离**，明明该涨就是不涨。
- **底部钝化警告**（第61688行）：MACD 出现金叉股价却一路向下，KDJ 背离后可**再次背离、在底部走平不动**——熊市抄底别信指标。
- **顶/底背离**：股价创新低但 MACD 不创新低=底背离（底部反转信号）；股价创新高但 MACD 不创新高=顶背离（顶部反转信号）。但背离后可**再背离**，不可迷信。

### 2. KDJ / BOLL（作者几乎不用，列为"失真指标"）
- **KDJ**：超买超卖、金叉死叉、J值。作者态度：极端行情下指标全失真，KDJ 背离后还能再背离、底部走平不动。
- **BOLL（布林带）**：上轨中轨下轨、缩口扩口。作者只在吐槽"全套看空信号"时提及（MACD下行+绿柱放大+KDJ下穿+BOLL下轨无支撑），认为远不如 K线+量可靠。

### 3. 均线（第55章：可看但别神化）

**【5日线——最常用】**
- K线站在5日线上 = 场内筹码交换活跃、主力边拉边洗（**不等于**个股强势）。
- 强势上升个股沿5日线走**约45度斜率**，换手率高、成交量持续放大。
- **第一次回踩5日线**=正常，持股；只要还在5日线上就视为强势。
- **5日线作用**：只看场内筹码成本变化，**仅参考、不作交易依据**。主力常"等待5日线靠近"=等场内平均成本接近。

**【10日线——短线买点】（第240章）**
- 强势股第一次从5日线回踩**10日线**=短线进场好机会。
- 跳空缺口后股价在5日均线上横盘，**第一次跌破5日线触碰10日线**时=买点。
- 第二次跌破10日线则可能触及20/30日线（谨慎）。

**【20/30/60日线——强支撑】**
- 创业板只要回调到**20日均线**就强势反弹、再上台阶=20日线是牛市强支撑。
- 跌破20日线后触20日线回落=反压，转弱信号。
- **60日均线**盘中跌破当天收回=强势。

**【均线骗线手法（重要陷阱）】（第216章）**
- 底部洗盘时，主力让股价站上5日线后，**突然一根大阴线同时跌穿已走平的10/20/30日线**，形态极难看 → 吓跑技术派散户；第二天却**高开快速拉回**=洗盘完成。
- 牛市中主力会突然用一根3%-6%大阴线**一口气跌破几根"重要均线"**，造成要下跌的假象 → 实为洗盘。
- **讽刺"不断改参数"**：有人用7日/14日/21日等非标准均线故弄玄虚，被跌穿后不断后画新线（7日→生命线→天下线→730日两年线），只说猜对的、绝口不提猜错的。**均线跌破就是跌破了，别不断改参数自欺欺人**。

### 5. K线组合与形态

**【缩量双顶/M头——见顶信号】（第13章）**
- 第二高点价创新高但**成交量比前一高点萎缩** = 主力偷偷出货。配合穿头破脚大阴线确认。
- 作者总结见顶两大标志：①单顶=高位天量+穿头破脚大阴线；②缩量双顶。

**【双底/W底——"得双底者得天下"】（第90、367章）**
- 确认底部必须二次探底确认（"一只脚站不稳，两只脚才稳"）。
- **二次探底位置通常低于第一次**（砸出新低），当天K线组合往往还要继续大跌的样子 = 极度凶险难看，吓人割肉。
- 二次探底收**金针探底/大长腿T字且踩住前期平台** = 底部确定。
- **周线双底比日线更可靠**。

**【岛形反转】（第459章）**
- 因缺口存在，几根K线与前后K线远远脱离，如海岛悬于海外。
- **底部岛形反转（向上）**→ 大概率翻倍甚至几倍（买点）；**顶部岛形反转（向下）**→ 连续杀跌（卖点/避险）。
- **真/假反转判断**：真的=突破放量、回踩缩量，确认缺口有效后继续放量上升；假的=突破后一路拉升不回踩、量能越走越低，最终失败掉头跌下。
- **经典买点组合**：放量跳空→以缺口回补缺口→缩量回踩→始终站在缺口上方。

**【螺旋桨走势】（第399章）**
- K线上下有规律震荡（如直升机升降），**周线图**看最清晰，是长期底部蓄势形态（创业板2012年盘整一年）。
- 配合"横有多长，竖有多高"——底部横盘越久，爆发越高。

**【底部涨停板洗盘法】（第8232行，主力惯用）**
- 组合序列：底部震荡→小阴小阳拉高十几点→突然砸两根5%阴线（或跌停）→第二天缩量大阳反包+缩量涨停→涨停次日放量大阴线+低开破位中阴连跌两三天→止跌企稳时再猛砸一次收长T字。
- 威力点：涨停后第二天的放量大阴线+连续跳空低开下杀，足以让散户以为主力出货跑路。
- **应对**：识别这是洗盘而非出货，不交出带血筹码。

**【箱体/平台整理】**
- 牛市中底部明显放量突破长期震荡箱体=必涨行情。
- 小平台（如某根放量大阳线形成）被回踩确认有效=支撑有效→向上冲击。**回踩平台+缩量**=波段买点。

### 6. 缺口/跳空（全书反复强调，235次出现）

**【加速的判定——关键！】（第176章）**
- **有效加速 = 必须出现跳空缺口**。没有跳空缺口的加速="无效加速"。
- 上涨加速=拉涨停板；下跌加速=连阴后中阴+跌停组合。
- **持股卖点**：等到主力资金**加速（出现跳空缺口）后再卖**，让利润奔跑。

**【缺口如磁铁】（第574章）**
- 缺口会吸引指数/股价向缺口方向运行，至少会试探。

**【上涨缺口回补=走弱信号】（第920章，重点）**
- 上涨缺口被回补 → 证明**这一轮上涨结束**，趋势继续向下，一个台阶比一个台阶低。

**【缺口作为支撑/防线】**
- 股价回到前期跳空缺口上方整理 + **守住缺口不回补** = 强势，可持有。

**【跳空缺口吓盘洗盘】**
- 连跌后跳空低开大跌 → 上午吓散户割肉 → 收盘拉回补缺口 = 凶猛洗盘。

**【三个下跌缺口衰竭——买点】（第459章）**
- "一而衰、再而竭、三而竭"：连续出现三个下跌缺口，空方力量衰竭，此时进场，判断主力必然回补上方缺口+反抽确认第二个缺口的压力。

**【突破缺口回踩=买点】（第437章）**
- 底部涨停板跳空缺口后，股价会上涨回落**测试缺口支撑+洗盘**；若不回补缺口=强势，可追。

### 7. 支撑/压力/趋势线/整数关口

**【突破压力→回踩→压力变支撑】（第274、357章）**
- **机制**：突破压力位时套牢盘被解放 → 主力略拉高再砸回 → 解套者怕再套、微盈卖出 → 该区域完成有效换手、抬高平均成本 → 后来跌回此处的人觉得"便宜了"再买 → 形成支撑。
- **人性原理**：多数人10元买入15元卖出后，14、12元都觉得贵；回到10元觉得合理才买（"可乐价格"心理）。
- **操作**：突破后回踩前期高点（压力位），踩住=有效突破可进；踩不住=假突破。

**【密集交易平台=支撑/阻力核心】（第191-193章）**
- 前期密集交易平台是套牢盘集中区。主力突破时一般**放量拉升解放套牢盘→冲高15%→倒仓放巨量大阴线跌下→但不跌破突破平台**。
- **选短线标的**=找**温和放量接近前期密集交易平台并突破**的股票。

**【有效跌破 vs 盘中跌破】**
- 盘中跌破=交易时段跌破但收盘收回（不算破位）；真正有效跌破=收盘没收回，且随后两交易日上冲遇该位又跌下。

**【不破不立】（第750章）**
- 牛市到压力位主动回撤整理，吓套牢盘割肉。
- **熊市相反**：要跌破密集交易平台，让人觉得没支撑，割肉后才拉起来。

**【整数关口】（第306章）**
- 1000/2000/3000点等 = **心理作用**为主（如99元vs100元），非真实技术位。冲击整数关口前常先砸（逼套牢盘割肉）。

**【趋势线】**
- 不破趋势线则对股价波动毫无心理波动（第八境界）。
- 陷阱：被跌穿后不断后画新线自欺欺人。

### 8. 波浪理论

**【ABC调整】（第300+章）**
- A浪下跌结束 → B浪反抽 → C浪猛烈下杀。
- B浪反弹高度 ≈ A浪开始时那个十字星的最高点。
- C浪/3浪下杀幅度一定很猛烈，才能吓出筹码。

**【小5浪调整】（主升浪前）**
- 主升浪前的调整多走小5浪震荡，当成交量缩小、股价走平，才会突然最后拉升。

**【主升浪】**
- 前期反反复复，至少2年；只有最疯狂阶段才天天涨。
- 突破长期盘整平台后才确认；拉升斜率未到主升浪前必回调整理。

### 9. 分时图技巧

- **分时均线**：股价跌到分时均线上立即有大单承接=主力托盘；分时均线大概率不跌破=强势；股价不触碰分时均线=极强势控盘。
- **尾盘拉涨停**：第二天**大概率高开低走**，可能是穿头破脚大阴线 → 高开时卖出。
- **集合竞价骗线**：9:19:40主力撤单，营造高开6%假象+前一天放量大阳 → 骗散户挂买单（9:19:59前没撤就成交被套）。

### 10. 技术分析总原则（贯穿全书）
1. **成交量和换手率做不了假**，是最核心、最可靠的判断依据（第47章）。
2. **K线要好几根连起来看**（技术组合），不能只看一两根；**周线图比日线图准确**（日线易骗线）。
3. **任何指标都只是参考，不能作交易依据**（第56章）——必须 K线+成交量+换手率综合判断。
4. 所有K线/形态的本质是为"筹码消化/换手/抬升成本"服务——看懂筹码逻辑，K线自然看懂。
5. **牛市急跌慢涨，珍惜每次下跌；熊市每次反弹都是逃命机会**。
6. 趋势是**走出来的不是预测出来的**，收盘后每天复盘K线+量能，再综合这段时间走势分析。
