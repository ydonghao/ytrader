一、股票不是虚无缥缈的东西

股票的本质是上市公司的股权，买股票就是买公司——这句话在这个系列课程中，我应该会强调很多次。今天跟大家讲一下我们的公司和行业，起码让大家知道，我们投资的这些公司是怎么来的。

有很多人会觉得股票的风险高，是因为觉得股票是一个虚拟的东西。特别是跟房地产放在一起对比：房价哪怕再跌，起码还有个房子在那里，会给人一种有安全底线的心理暗示。但股票就不一样了，它看上去就是虚拟的——那万一跌没了怎么办呢？钱不就没有了吗？我知道有相当多的新手股民都是这样的想法。

所以我今天跟大家讲一下我们国家公司的情况，让大家了解清楚我们投资的这些公司是怎么来的。

二、公司是如何注册的

如果我们自己要创业，第一步就是先注册一家公司。这表明你的业务被纳入到了公司法的管理体系下，也纳入到了税务体系。大家不要觉得一提到监管就有种很抵触的感觉——与其说是监管，不如说是通过接受监管，获得了政府的信用背书，公司的各项业务都降低了沟通成本。

比如说你开展业务需要去招聘，如果没有注册公司，别人一看就会怀疑你是哪里来的草台班子，连个公司都没有；你跟其他公司谈合作、谈业务，没公司你连发票都开不出来；客户万一使用了你的产品和服务出了问题，在没注册公司的情况下，基本上是不会和你合作的。再加上一些其他的限制，在不注册公司的情况下，我们是没有办法进行经营类工作的。

但在你注册公司之后，这些业务就能顺利开展了。法律法规给我们的经营活动提供了一个基础的信用背书；对于创业者自身而言，也能起到一个风险隔离的作用。

做生意的风险是非常高的。公司是企业法人，具有独立的法人财产和法人财产权，公司的全部财产对公司的债务承担责任。所以只要合法经营，就算是失败了，公司就破产呗，对你个人的独立经济情况是不会造成很大影响的。

现在注册公司是一件比较容易的事情，基本上可以说是零成本，只要你有能力把业务开展起来，注册公司就是顺手的一件事。现在注册公司也不用你自己去跑，可以找一家财务公司去代办，后续用他们的代账服务就行。代账的价格一般是 200 块钱一个月。初创小公司一般是没有财务的，都是代账公司去处理税务的事情；财务公司一般会免费帮你弄注册的事，你提供一些注册信息就可以了——比如想好公司的名字（要多准备几个，避免注册时重复）、提前准备法人和监事的身份信息、确定公司的业务范围，基本上几个工作日就能注册好。拿到营业执照之后，去银行开个公司账户就可以合法经营了。

三、认缴制与实缴制的变迁

在 2014 年之前，公司的注册资本用的还是实缴制度：假定一家公司的注册资本是 50 万，就要求两年之内要把这 50 万 从私人股东账户转到公司账户。这个注册资本就是公司的初始启动资金，代表公司的基本经济实力，可以影响客户和合作伙伴对于公司的信任度。之前这个门槛还是挺高的——很多人想开公司做业务，因为都是白手起家，可能就拿不出钱来交这个注册资本。

后面为了鼓励大家创新创业，2014 年之后就由实缴制度改成了认缴制度。认缴制度就是在注册公司的时候就不用验资了，注册资本填个数就行了，后面根据公司的章程可以后续再缴纳。但在实际操作下，对于小微公司来说，基本上后面就不会再管这个注册资金的事情了。

不过从去年开始，这个认缴制度又回调了一点，改为在 5 年之内要按照注册资本把资金转进来。我估计是过去 3 年多时间经济不好，公司倒闭了很多，然后产生了很多经济纠纷——由于之前没有搞这个实缴制，很多公司都是空壳公司、账上没钱，出了事情没钱赔，然后打官司的事情多了。所以监管对这个注册资本的缴纳又重新提了要求。不过在我看来，5 年也算没什么门槛，因为公司经营 OK 的话，5 年时间里这个注册资本也该赚回来了。

四、公司信息的公开查询

注册完毕之后，公司的信息就登记在工商的数据库了。工商的网站可以查询到所有公司的信息——小到我们家门口的小卖部，大到上市公司，这些注册信息都是公开透明的。不过这个网站非常卡，可能访问的人太多了吧。

我们一般查询企业的信息，会去天眼查这种工具上查询。我们在做股票投资的时候，经常会用到这些信息，比如说调查公司的股权架构，直接去工商网站查可以一层层地追溯公司的股权结构，非常方便。

做实体生意的人也会经常用到这些信息。对于一些不熟悉的新的合作伙伴，除了可以查到基本信息之外，还可以查到一些法律纠纷的信息，就可以提前避坑。

政府对公司的信息也会进行一些大数据分析，然后制定相应的政策。比如说他们会去了解公司新注册的数量和注销的数量，基本就能判断现在实体行业的景气度；然后分析各个行业的公司数量的增减情况，就能够根据行业的需求，制定一些更加匹配的政策。

五、公司的核心：产品与服务

讲完公司是如何登记注册的，再讲一下公司是如何开展业务的。一个公司最核心的东西，就是它能提供什么样的产品，或者提供什么样的服务——公司所有的经营动作，都是围绕产品和服务进行的。

如果我们自己要进行创业活动，第一件事情就是先构建出自己的产品和服务，然后围绕产品和服务去推进，去找到你的客户、完成签约和交付。

小到路边的地摊小卖部，提供的是零售服务；大到腾讯和茅台，提供的是社交网络和白酒饮品。我们熟悉的所有上市公司，都有代表性的产品和服务。比如：

公司代表性产品
小米之前是手机，现在是汽车
茅台飞天系列白酒
腾讯QQ 和微信
字节跳动抖音

我们在看股票的时候，第一时间要想到和研究的，就是他们家的代表性产品。公司在小的时候，团队只有几个人，大家的工作重点主要就是把产品做出来，然后再把产品卖出去；等公司发展壮大了，其实要做的事情还是把产品搞出来，然后再把这个产品卖出去，只不过大家的分工会更细化、更专业一些。

六、成熟公司的五大业务线

成熟公司一般都有这五大业务线：市场、产品、营销、交付和售后。这五个业务线可以形成一个循环——根据公司的规模和类型不一样，具体内容可能会略有差异或相互兼容，但基本上都有这五大职能。

  • 市场部门。负责开拓公司的市场，比如市场活动、广告投放、产品宣传等。小公司一般市场和营销是合并在一起的，统称市场营销部。比如我们经常看消费行业——手机、汽车都很喜欢开发布会，这些活动就是市场部的同事负责安排组织的。
  • 产品部门。主要工种是产品经理，基于对客户的需求，不断地设计、打磨并生产出符合客户需求的产品与服务。
  • 营销部门。负责把产品卖出去，根据公司的性质有不同的卖法，所以需要的营销能力也不一样。如果产品面向个人消费者，营销部门的重点工作可能是销售渠道的建设、如何快速把公司的产品铺出去；如果是面向企业的产品，营销部门一般是关系型销售和方案型销售，要去研究客户的采购流程、理清客户关系人之间的关系、为客户定制专属的产品方案，以此来促进成交。
  • 交付部门。营销部门签约之后，交付部门负责把产品交到客户手上，在很多公司又被称为项目部或者工程部。比如我们家里装修去买橱柜产品，不是这个东西我们拿回家就能用的，而是需要工人师傅去测量、去定制、去安装调试，它是有一个交付过程的。
  • 售后部门。我们在使用产品的过程中如果有什么问题，就要去找售后部门解决。售后的同事在处理完这些问题之后，会将问题进行汇总分析，得到一个改进方案，然后反馈给上游的几个部门，就形成了一个业务闭环。

七、三大职能部门的搭配

公司大了之后，光有这些业务部门也是不行的。业务部门这么多人，人员需要招聘、需要培养和晋升，就需要"选、用、育、留"，所以就要有配套的人力资源部，也就是我们俗称的 HR。然后人多了的话，办公室的环境需要维护、办公器材需要置办、还有公司的各种资产调度的工作，这就需要行政部门了。公司开展各项业务都需要资金：卖掉产品需要回款、需要支付采购的货款、需要支付员工的薪酬、需要按时缴纳相关的税务、需要进行投融资活动，所以就需要财务部门。

在以前，一般公司成规模之后都是需要行政、人力、财务这三大部门的。不过到了最近 10 年，随着新技术的发展，各行各业做业务都离不开 IT 技术，所以现在很多公司都还有独立的信息技术部。

稍微成熟的公司部门架构一般就是这样的：五大业务部门和三大职能部门进行组合，只不过根据公司的大小和类型，细节上会有些不同而已。

不同阶段的部门演化

  • 公司发展早期，市场和营销通常是放在一起的，后面才会分开。
  • 产品部门一般先看公司类型：如果是产品型的公司，那产品部门就是独立的部门，而且是公司的核心部门，职能会进一步细分为设计部、工程部、质量部等；如果是服务型的公司，那公司内部就会弱化"产品"的概念，核心部门就是项目部门——但从本质上讲，公司提供的服务其实也可以理解成一种产品形态。
  • 公司比较小的时候，财务可以请代账公司帮忙，需要一个懂财务的合伙人负责就行了；公司的行政和人力一般最开始都是一个部门，等公司规模做得比较大时，行政和人力才会分开。一般重资产类的公司行政部门的重要性会高一些，他们需要调度公司的资产；轻资产公司的话，基本上行政就会一直挂在人力资源部的下面。

以上这些信息，对于接触现代企业运作比较多的人来说其实算是常识，大家都基本上都知道；但还是有相当一部分人是不清楚这些的，所以课程设计上我要把这个内容给过一遍——让大家明白，股票背后的公司，是一个看得见摸得着的经营实体，而不是什么虚无缥缈的东西。

八、从业务场景看懂股票

了解了这些信息之后，我们再去看股票，就能有一个更加具象化的理解。我们就知道那个六位数的代码背后，是一家公司在辛苦地运作：有销售人员在为客户做方案，有产品的同事在设计新产品，工厂的工人在加班加点地制造，然后负责交付的同事会把这些产品交付到客户手上；在交付产品的同时，还会给客户提供财务部门同事开出来的发票，然后等客户验收之后，回收产品的款项。

在了解到这些业务场景之后，我们才能找到切入点去研究公司的价值，然后做出我们的投资。选分析公司以及评估公司的价值，是后面单独要讲的章节。今天我只讲两个最重要的分析切入点：一个是公司的产品是否具有竞争力，另一个就是公司的商业模式。

九、产品竞争力：定价权

公司的所有业务都是以产品为中心围绕展开的，产品的竞争力就是一个公司的绝对核心。所以我们要投资股票也就是投资公司，最重要的一点，就是看懂公司的产品。

所以我们在选择投资目标的时候，有一个很重要的原则：你得看明白这个公司的产品。即便是不能完全分析清楚，但起码你要接触过他们的产品，不然的话你是没有办法去分析出这家公司的价值的。做不到这一点的话，想要通过投资公司去长期稳定地盈利，几乎是不可能的。

判断公司的产品力，有一个非常好用的方法叫定价权，就是考虑公司的产品具不具备定价权。定价权不是一个绝对的概念，不是说公司产品的价格它想卖多少钱就卖多少钱，而是和行业内的其他竞争对手相比，公司的产品具有优先定价的权利，然后竞争对手的价格都需要参考这个公司的产品进行定价。

定价权的真实案例

  • 苹果手机：所有厂商的旗舰手机，在之前很长时间内都要参考苹果手机的定价——因为我们每个人都有手机，在买手机的时候都会思考这个问题。
  • 华为折叠屏：华为的 X 系列突破了苹果手机的定价权，因为苹果是没有折叠屏产品的，而这个领域应该是目前华为做得比较好的，所以华为的 X 系列就是一个具有定价权的产品，其他厂商推出折叠屏手机就要先参考华为的定价。
  • 特斯拉 Model 3：我们国内的新能源汽车这几年虽然说都做得很好，但是在 Model 3 这款车面前，相同级别的产品定价都要先参考特斯拉 Model 3 的定价。
  • 小米汽车：今年开始小米的电动车比较热门，头两款产品刚好和特斯拉卖得最好的两款产品在定位上重叠。我们其实可以观察一下，小米汽车有没有可能挑战特斯拉的产品定价权。

这也说明了，公司的产品定价权不是一劳永逸的，也是需要公司持续研发和创新产品来巩固的。所以我们在选择上，尽可能地考虑投资产品具有定价权的公司。如果公司的产品没有定价权，那公司的利润和增长其实都很难保证，只能说是在行业整体发展都 OK 的情况下，能够取得比较好的增长；一旦行业遇到增长困难，产品没有定价权的公司就很容易变成供应链上的利润牺牲者。

十、商业模式的三种类型

除了对产品力的分析之外，另一个重要的分析维度是看公司的商业模式。如果只有产品有竞争力、但商业模式不好的话，公司的投资价值也是有上限的。商业模式分析是一个极其重要的分析，所以会在后面专门有一个章节讲商业模式，这里就只先简单介绍一下。

商业模式其实不是什么很高大上的专业术语，也不是很复杂的东西。可能很多人之前没接触过或者没想到这上面来，所以没有专门的总结提炼过。商业模式通俗点讲，就是企业赚钱的方式——有的赚钱方式比较差，赚白菜的钱；有的赚钱方式很容易，可能就躺着啥也不用干就把钱赚了。

商业模式类别其实也不是很多，主要分三类：

  • 服务型公司。随处可见，类型最多的公司就是服务型公司。
  • 产品型公司。是上市公司中类别最多的公司。这里问题就来了：为什么上市公司中不是服务型公司最多？原因很简单——服务型公司由于商业模式的限制，一般是做不到上市的量级的；能够达到上市公司的水平，基本上都是产品型公司。
  • 平台型公司。通常被称为平台公司，他们的产品只租不卖，你要使用的话就要源源不断地去支付这个租赁费用。

商业模式没有绝对的好坏之分。顶级的服务类公司要比大部分平庸的产品公司要好，顶级的产品公司也能媲美平台型公司；但我们在不考虑特殊情况下，一般还是看这个金字塔——越往上的商业模式确实会好一些。商业模式的内容必须结合案例来讲，这里就简单讲一下，重要的内容留到后面的独立章节。

十一、散户适合投的三类行业

讲完公司的注册、组织架构和商业模式之后，再讲一下公司的所属行业。

我们最开始在注册公司的时候，要选择公司的业务范围，这就属于行业的划分。行业的划分有很多种，我一般就看那个股票软件上提供的行业划分。这个其实没有所谓的好坏，能区分清楚就行了——它只是一个统计方法而已。按照股票软件提供的标准，国内行业被分为 56 个大型行业和 110 个细分行业。

有些行业是比较适合散户投资的，而有些行业是不适合散户投资的，风险非常大。其中有一个非常重要的理由前面也讲过了：就是有些行业的产品，我们普通人是接触不到的。如果我们接触不到公司的产品，我们就没有办法去分析公司的产品竞争力，也就没有办法去判断公司的价值。

我这里对行业做了一个简单的划分，把行业划分为三类：

第一类：适合普通人投的行业

主要以消费品为主，都是我们在日常生活中能够体验到产品的公司。即便是我们专业度不够，但也不妨碍我们从消费者的视角去评估公司的产品。比如说像汽车行业、像手机行业等——我们普通人哪里懂得汽车行业的专业问题呢？但是只要我们会开车，我们就能评价车的好坏：我们知道这辆车长得好不好看、开起来快不快、加速猛不猛、减震的舒适性怎么样、智能化怎么样，我们就会得到一个相对靠谱的评价。

这类行业主要有：食品饮料、家居家电、纺织服饰、汽车整车、消费电子这些消费类公司。这些行业都是大行业，所属公司非常多，绝对够用了。比如说 A 股常年霸榜的茅台属于食品行业、小米属于汽车和消费电子、美的和海尔属于家用电器，这些都是比较热门的公司。

第二类：需要一定专业度的行业

但也不是不能投。专业度要么比较简单、通过学习也能掌握一些；要么就是行业自身的从业者可以选择。

比如说银行保险这类，虽然专业度很高，但是行业历史悠久、标准化程度比较高，业务的复杂度早就被研究透了，掌握起来难度不是很大。然后还有一些固定资产类的，比如说以长江电力为代表的水电——虽然我们不能直接接触到这些公司的产品，但公司的业务比较简单，就比较容易解读。然后还有医药、医疗和制造业等，这些也都是大行业，公司非常得多。虽然行业专业度比较高，但是产品我们基本上能够间接地接触到。对于行业外的人可能难度稍大一些，但对于行业内的从业者来说不算什么难事。

第三类：不太推荐普通投资者选择的行业

这些行业相对很冷门，公司的业务基本上和普通人的生活是没有关系的。比如说资源类的公司——煤炭、石油、化工、环保等，这些资源类的公司都是周期性的公司，公司业绩受到的影响因素比较多，普通人是没有能力去研究分析这些的；或者说是能研究清楚，但需要下非常大的功夫，然后研究透了，这些公司的投资收益率可能也就很一般，还不如节约点精力搞搞简单的行业。这种的话就是除非你是行业内的人，否则就不要想了。

十二、从市值最高的公司看共性

然后我们可以换一个角度来看一下行业和公司的选择问题。投资公司不就是为了公司能够长期稳定的高速增长、公司的股价越来越值钱嘛。我们就直接看现在中美两国市值最高的公司有哪些，以终为始就可以了。

排名中国市值最高美国市值最高
1腾讯（人人都在用）苹果
2阿里巴巴（人人都用）微软
3四大行（也有个人业务）谷歌
4茅台（高端饮食消费，用户相当多）英伟达（显卡 / AI）

中国市值最高的公司应该是腾讯，腾讯的产品是不是人人都在用？排行第二的应该是阿里巴巴，这个也应该是人人都用的吧。再往下的话是四大行，四大行虽然说主要的客户是企业，但是也都有个人业务，也是人人都能接触到的。再往下就是茅台，茅台确实不是人人都在使用的，它属于高端饮食消费，但是使用的人口也是相当大了。

这是中国的头部公司。我们再来看一下美国的头部公司：苹果、微软和谷歌——只要我们现在打开电子设备，基本上就是这三家的产品，你绕不开的吧。往下还有英伟达，玩电脑必备的显卡算是直接使用，AI 的话算是间接使用。

全世界能够做到顶级的巨头公司，
产品基本上都是面向普通用户端的。

所以我们其实没有必要去看那些业务离我们太远的公司——浪费精力不说，投资的成绩可能也不会特别理想。
