复盘公牛集团股价走势

一、缘起：从一只充电插座想起公牛集团

我今天买了一个公牛的充电插座，就想到了公牛集团这只股票，顺便就看了一下。不知不觉，公牛集团上市都已经 3 年了。

当时 2020 年上市的时候，我还记得关注度挺高的，因为这也算是比较明星的公司。刚好 2020 年是那波白马股的大牛市，公牛集团的股价也暴涨了很多，翻了很多倍。当时我印象很深，本来是打算买一点的，还发过文章分析过一次，但那次白马股的大行情把股价推得太高了，所以最终没买，就一直观察。

二、三年原地踏步：市值停在白马行情顶峰的回调区间

现在都已经 2023 年了，跟当时比已经过去 3 年多。看了一下 K 线，我发现这家公司的市值 3 年来基本就是原地踏步，目前仍处在 2020 年白马股行情顶峰之后的回调区间里。

也就是说，这只股票你只能低买高卖、做差价，赚点投机的钱。如果长期持有，除非是上市初期连续涨停的时候抢进去，否则这三年基本上没什么收益率，大部分时间账户持仓可能都是浮亏的。

三、业绩持续增长，平均年增约 10%

虽然说股价 3 年没怎么涨，但公司的业绩其实说得过去。公牛算是很明星的公司，平均下来还是有 10% 左右的规模增长，这个数据上可以看得比较清楚。

如果硬要把公牛当成成长股来看，3 年平均 11% 的增长显然是不够看的；不过考虑到这 3 年的情况比较特殊，业绩还能持续增长，也算说得过去。

四、用时间换空间：优质公司的估值消化方式

业绩在持续增长，公司的市值却原地踏步——这种情况下，我认为就是用时间去消化高估值。

A 股里面大多数品质一般的公司，都是用股价大跌去消化高估值；而公牛这种比较优质的公司，能用"时间换空间"已经算不错了。虽然没挣钱，但账面上起码不浮亏，只是损失了资金的时间成本，差不多相当于 3 年资金零收益。按照无风险收益 4% 来算，这其实就是亏损的。

五、2020 年大白马行情的结局

从公牛身上，我们可以看到 2020 年那波大白马行情的一个结局。

把时间拉长来看，就能得到一个结论：高估值必然不能持久。公司的经营也是遵循客观规律的，不可能所有的高估值都能通过高增长来消化。即便是这几年最牛的公司——宁德时代和比亚迪，今年的跌幅也都比较大；大多数情况下，股价都会出现暴跌，比如海天味业已经跌了一年多、跌了 70% 多。

相比之下，公牛这种用时间换空间的方式，已经算比较温和了。只是我没想到，这事过去 3 年了，估值消化的时间比我预想的要久得多。

六、小结

转眼已经过去 3 年，就借这个节点复盘一下公牛的股价走势。核心教训很简单：不要在估值泡沫期追高买入，哪怕是最优质的明星公司。
