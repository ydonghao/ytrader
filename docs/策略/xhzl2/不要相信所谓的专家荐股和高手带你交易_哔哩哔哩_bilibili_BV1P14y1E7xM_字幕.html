不要相信所谓的专家荐股和高手带你交易

  5. 从重仓到清仓：行情来了随时调整

一、观点先行：荐股、带单一律不可信

今天想跟大家分享一个观点：我们在网上碰见那些推荐股票的、所谓"大师带你交易"、"建个群带你操作"的，一律不能相信。

这并不是空泛的判断，我自己有这方面的切身体会。我有一些线下真人认识的朋友，他们看我投资做得还可以，就问我："我能不能跟着你操作？你买什么我就买什么，这样是不是就能盈利了？"

我给他们的回答是：这样想是不可能的。我自己之前也尝试过带人，结论是几乎不可能跟得上。

二、第一个原因：你不可能被百分之百上心地带

第一个问题在于"上心程度"。我教自己的孩子，可能会手把手地教，每天都会去看一下情况；但你去带外人，你不可能做到百分之百上心。

这是带单这件事本身的结构性缺陷，跟带你的人是谁无关——即便对方真的愿意带你，他也无法做到像对待自己账户那样对待你的账户。

三、第二个原因：操作链条漫长，难以同步

第二个问题更致命：整个股票操作是一个很漫长的过程，你不一定跟得上。

我们可以用一个例子来拆解。假设我们平时去谈论某只股票，可能只是觉得这家公司的商业模式挺有意思，或者说最近的行情刚好是这只股票的行情——我们谈论，并不代表我们看好这家公司。

即便假定我们真的看好这家公司，也可能只是觉得这家公司的产品还不错、比较有前景，但公司价格可能不合适，那我们也不会去买。也就是说，"看好"和"买入"之间，还隔着估值的考量。

四、从看好到买入：可能只是底仓试水

就算看好了、也买了，背后的情况仍然复杂：

  • 可能是觉得仍然拿不准、有不确定的东西，先清仓买一点试试看，买个底仓放着，后续再观察、再持续加仓。所以买了也不见得是重仓。
  • 或者是买了、非常看好、确定性很高，于是重仓买入——但重仓不一定是长期持有。

五、从重仓到清仓：行情来了随时调整

即便是重仓买入，也可能因为突然来了一段行情，几天之内就涨了很多。这个时候从长期收益率的角度讲，可能就会卖掉很多，把重仓变成清仓——它不一定是长期持有的。

又或者，重仓买入、又长期持有，但中途并不代表你不去做T。可能某段行情比较低迷时会抄一点，涨起来时又会卖一点，用来摊薄成本。

六、链条上任何一个环节脱节，结果都会偏差极大

所以你看，从看好 → 买入 → 清仓 → 重仓 → 长期持有 → 做T，这条链条上：

只要有一个环节你没跟上节奏，
最后的投资结果就会和实际结果偏差非常大。

从这个角度讲，你不可能靠跟着别人操作来挣钱。除非行情好、运气好——但那不是能力，长期来讲靠运气是靠不住的。

七、结论：只能依靠自己的能力去学习、去决策

所以最终的结论是：

长期来讲，我们最终只能依靠自己的能力去学习，依靠自己去做决策。这是在股市中能够长期稳定获利的方法。
