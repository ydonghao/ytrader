# 股票投资课程（从入门到精通）— 系统化功能设计

> 来源：`docs/策略/xhzl/股票投资从入门到精通/` 全部 31 篇课程字幕。
> 目标：把课程中**可量化、可代码化**的分析方法，系统化为后端 `ytrader` 的功能模块。
> 本文档先给"功能全貌（6 簇）"，再给"本次实施范围"，最后给"后续路线图"。

## 0. 与现有系统的对照基线

后端已有能力（落地时优先复用，避免重复造轮子）：

| 能力 | 位置 | 说明 |
|---|---|---|
| 三大报表全科目 | `stock_financial_detail`（固定列 + `detail` JSONB 195 科目） | 营收/成本/三费/净利/货币资金/应收/存货/固定/商誉/总资产负债/权益/短借/长借/OCF/ICF/筹资CF/capex/FCF |
| 估值日线 | `stock_valuation` | PE/PE_TTM/PB/PS/dv/dv_ttm/total_mv |
| 派生价值指标 | `fundamental/derived_metrics.py` | ROIC/EV/EBIT 收益率/FCF Yield/ROA/有息负债/投入资本 |
| DCF | `fundamental/dcf.py` | 两阶段 DCF + 安全边际 |
| 股息率 | `fundamental/dividend_yield.py` | TTM 每股股息 / 股息率 |
| 历史分位估值 | `fundamental/percentile[_batch].py` | PE/PB 经验分位（3y–20y，可排除炒作区间） |
| 多模式选股 | `strategy/longterm/screener.py` | magic_formula/dividend/fscore/custom/dividend_value |
| 长期回测 | `strategy/longterm/` | 7 策略 + 优化器 + 绩效指标 |
| 宏观指标 | `macro_indicator`(+meta thresholds) / `macro_view` | 含阈值/方向/参考线 |
| 组合/风险 | `portfolio/`、`risk_router` | NAV、VaR/CVaR、行业暴露 |

**关键陷阱备忘**：`stock_financial_detail.fcf` 列实为**筹资活动现金流净额**，**不是**自由现金流；自由现金流是 `free_cash_flow`（= OCF − |capex|）。

## 1. 功能全貌（6 簇）

### 簇 1：财务质量诊断（docs 08 / 12 / 13 / 19 / 21）★ 本次实施
课程中最受强调、定义最精确的一组。回答"这家公司财务上健不健康、是不是垃圾公司"。全部为三大报表纯函数，系统目前仅有 ROE/毛利率/净利率/资产负债率/FCF，**不覆盖**以下维度。

| # | 功能 | 公式 / 规则 | 阈值 / 判定 | 来源 |
|---|---|---|---|---|
| 1.1 | 收现比 | 销售商品提供劳务收到的现金 / 营业收入 | >1 强势（先款后货）；长期<1 回款差风险 | 08/13 |
| 1.2 | 净现比 | 经营现金流净额 / 净利润 | >1 利润质量高；持续<1 风险 | 13 |
| 1.3 | 现金覆盖短期债务 | (货币资金+交易性金融资产)/(短期借款+一年内到期非流动负债) | **<1 淘汰红线** | 08/12/19 |
| 1.4 | 应收款 vs 现金 | 应收账款(及票据) > 货币资金 | **触发即淘汰** | 12/19 |
| 1.5 | 费用/毛利比 | (销售+管理+研发+财务费用)/毛利润 | **<30% 强 / 30–70% 中 / >70% 弱** ★最精确 | 13 |
| 1.6 | 杜邦三因子 | ROE = 净利率 × 总资产周转率 × 权益乘数 | 定位 ROE 驱动来源（产品/效率/杠杆） | 08/13 |
| 1.7 | 经营性/有息负债拆分 | 经营性=应付+合同负债+预收；有息=短借+长借+应付债券+一年内到期 | 有息≈0 为佳（茅台） | 08/12 |
| 1.8 | 重/轻资产分类 | (固定资产+在建工程)/总资产 | >阈值 重资产 | 12 |
| 1.9 | 存货/营收比 | 存货/营业收入（时序趋势） | 占比走高=积压风险 | 07/12 |
| 1.10 | 商誉占比 | 商誉/总资产（+商誉/权益） | 偏高预警（减值/利益输送风险） | 12 |
| 1.11 | 毛利率商业模式分类 | 按毛利率分档 | >60% 定价权型 / 30–60% 中 / <30% 运营效率型 | 13 |
| 1.12 | 现金流阶段 | 投资 CF 符号 × 筹资 CF 符号 × 营收增长 | 扩张/收缩/成熟理想型四象限 | 13 |
| 1.13 | 成长停滞检测 | 近 N 年营收 CAGR；连续下滑期数 | 8 年 CAGR<3% → 停滞（格力案例） | 19/21 |
| 1.14 | **质量诊断聚合** | 上述指标加权聚合 + 淘汰红线否决 | quality_score(0–100) + red_flags + verdict(pass/review/eliminate) | 08/19 |
| 1.15 | 分红比例(派息率) | 年度分红 / 净利润 | ≤30% 正常 / 30–70% 慷慨 / >70% 高；>100% 掏空家底红旗 | 21/26 |

### 簇 2：估值增强（docs 15 / 21 / 24 / 25）★ 本次实施
回答"这公司值多少钱、现价贵不贵"。系统现有 DCF（单点）+ 历史分位（经验秩），**缺**参数化估值带、DDM、预期收益分解。

| # | 功能 | 公式 / 规则 | 阈值 / 判定 | 来源 |
|---|---|---|---|---|
| 2.1 | 均值±1σ 估值带 | PE/PB 时序均值 μ、标准差 σ，current 的 z-score | 超跌(<μ−σ)/合理偏低/合理偏高/虚高(>μ+σ)，默认 8 年窗 | 21/24/25 |
| 2.2 | DDM 股利折现 | V = D₀(1+g)/(r−g) | 红利股（长江电力：r=5.5%, g=2%） | 15 |
| 2.3 | 预期收益率分解 | 长期收益 ≈ 业绩增速 + 股息率 + 估值变化 | 目标 15% → 隐含增速门槛 >10% | 17 |
| 2.4 | 价值陷阱检测 | 低估值分位 且 成长停滞 | 触发=陷阱红旗 | 14/19 |
| 2.5 | 市值-业绩背离 | 区间市值涨幅 vs 净利/营收涨幅 | 市值涨>>业绩涨=泡沫 | 16/25 |

### 簇 3：组合与仓位（docs 22 / 23 / 24 / 26）— 路线图
回答"买什么、配多少、何时买、何时卖"。

| # | 功能 | 规则 | 来源 |
|---|---|---|---|
| 3.1 | 组合业绩换算（虚拟集团公司） | Σ(持股比×公司营收/净利/权益/分红) → 组合层 ROE | 22 |
| 3.2 | 成长×股东回报四象限 | 横轴成长 / 纵轴分红 → Q1–Q4，Q3 避免 | 23 |
| 3.3 | 风险偏好三档配比 | 防御 7:3:0 / 稳健 5:4:1 / 积极 3:5:2 / 激进 0:3:7（红利:蓝筹:创新） | 23 |
| 3.4 | 沪深300PE 驱动总仓位 | PE<μ−σ 满仓 / ≈μ 70% / >μ+σ <50% | 22 |
| 3.5 | 分批建仓规划器 | 估值合理偏低+K线高位→底仓30%，逐支撑位加仓 | 24 |
| 3.6 | FIRE 覆盖率 | 组合年分红 / 年生活开支 ≥100% | 22 |
| 3.7 | 买卖一致性原则（卖出触发） | 记录入场量化论点(如增速>10%)，论点破即卖；可结构化为 thesis-monitor 阈值触发 | 26 |
