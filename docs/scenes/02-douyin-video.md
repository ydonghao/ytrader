# 场景二：抖音视频脚本生成

## 目标

基于 NewsNow 热榜数据，自动生成抖音短视频脚本，把握流量窗口。

## 核心思路

利用热榜的跨平台时间差（微博/知乎先热 → 抖音后热）和实时性，生成三种类型的视频脚本。

## 三种视频类型

### 1. 热点追蹤型

话题已在抖音热榜 → 15-30 秒快速脚本，抢流量。

### 2. 先行机会型

话题在微博/知乎热了但抖音还没 → **最高价值**，提前准备，等话题爆发时第一时间发布。

### 3. 财经解读型

结合专业博客分析 + 热点标题 → "一分钟看懂 XXX"风格。

## Agent 流水线

```
TrendSpotter (复用场景一)

{

  "optimal_publish_time": "建议发布时间",
  "source_topic": "来源热点话题"
}
```
