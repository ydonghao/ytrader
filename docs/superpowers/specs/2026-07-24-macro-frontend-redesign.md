# 宏观页面重构 — 设计文档

> 日期：2026-07-24
> 状态：待评审
> 关联：macro-monthly-sync（数据层已完成，38 个指标已配置）

## 1. 背景与目标

宏观月度同步已实现 38 个指标的数据层（后端 job + API），但：
1. **数据未入库**：`macro_monthly` job 从未运行，DB 里只有旧的 12 个指标，新指标看不到
2. **前端展示不足**：现有页面是卡片网格 + 迷你图（12 点），无法深入查看单个指标的完整历史

**目标**：
1. 手动跑一次 `macro_monthly`，把全部 38 个指标的数据和元数据灌入 DB
2. 重构前端宏观页面为 **Tab 分维度浏览 + 指标详情展开面板**
3. 保留现有判断快照/历史验证功能，移入独立 tab

## 2. 前提：数据灌入

手动执行（一次性）：
```bash
cd backend && .venv/bin/python -m src.domain.market.sync.jobs.macro_monthly
```
此命令会：
- 拉 akshare 的 ~22 个指标（CPI/PPI/PMI/M1/M2/LPR/社融6分项/社零/商品房/工业增加值/固投/存款占比等）
- 导入 9 个 CSV 种子文件（11 个 akshare 缺口指标）
- 写入全部 38 条指标元数据到 `macro_indicator_meta` 表

验证：`GET /macro/dashboard` 返回的 `indicators` 数组长度 ≥ 30。

### 3.2 Tab 分组

Tab 按 `meta.group` 聚合，末尾追加"美国"（按 category）和"判断与验证"（现有功能）：

| Tab 顺序 | Tab 名称 | 筛选条件 | 指标数 |
|---|---|---|---|
| 1 | 通胀 | `group === 'inflation'` | 6 |
| 2 | 增长·就业 | `group === 'growth' \|\| group === 'employment'` | 13 |
| 3 | 货币·社融 | `group === 'monetary'` | 15 |
| 4 | 房地产 | `group === 'realestate'` | 3 |
| 5 | 贸易 | `group === 'global'` | 1 |
| 6 | 美国 | `category === 'us'` | 6 |
| 7 | 判断与验证 | （特殊：现有快照/验证功能） | — |

### 3.3 指标卡片（保留现有 + 改进）

卡片保持现有的紧凑布局：名称、当前值、日期、状态徽章、迷你折线图。**点击卡片**展开下方的详情面板。

### 3.4 指标详情面板（新增核心）

点击任意指标卡片，在该卡片下方（或页面顶部统一位置）展开详情面板，包含：

**① 关键数值 + 状态徽章**
- 当前值（大字号）+ 单位
- 报告日期
- 状态徽章（偏热/偏冷/中性，基于 threshold + direction 计算，复用现有 `badgeFor` 逻辑）

**② 完整历史折线图**
- 调 `GET /macro/indicators/{code}?limit=500` 获取完整时序
- 大图（高度 ~300px），不是现在的 64px 迷你图
- X 轴显示日期，Y 轴显示数值
- 参考线/阈值带（复用现有 `reference_lines` 配置）
- 当前点高亮
- Tooltip 悬浮显示具体日期和数值

**③ 指标解释 + 溯源**
- `meta.explanation`：详细含义解释
- `meta.doc_url`：外链"了解更多"
- `source` / `source_url`：数据源名称 + 溯源链接

**④ 历史数值表格**
- 同一接口数据，表格形式展示
- 列：报告日期、数值、单位
- **时间倒序**（最新在上）
- 可滚动（max-height + overflow），默认显示最近 20 条

### 3.5 判断与验证 Tab（迁移现有功能）

将现有页面的以下 section 整体迁移到"判断与验证"tab：
- 最新判断快照（含客观解读、AI 立场、宏观判断、资产预测）
- 手动记录判断表单
- 历史验证对照表 + 快照详情侧栏 + 预测期 K 线

功能逻辑不变，只是从默认页面移到 tab 内。

### 3.6 交互细节

- **Tab 切换**：点击 tab 切换内容区，URL 不变（纯 state，不走路由）
- **详情展开**：同一 tab 内，同一时间只有一个详情面板展开。点击新卡片自动切换；点击已展开的卡片关闭
- **数据加载**：卡片列表用 dashboard API（已有）；详情面板的完整时序在展开时懒加载
- **空状态**：某 tab 无指标时显示"暂无数据"

## 4. 改动范围

| 文件 | 动作 | 说明 |
|---|---|---|
| `backend/` （一次性脚本） | 运行 | `python -m src.domain.market.sync.jobs.macro_monthly` 灌数据 |
| `apps/web/src/pages/Macro.tsx` | 重构 | Tab 栏 + 指标卡片 + 详情面板 + 判断验证迁移 |
| `apps/web/src/pages/Macro.css` | 重构 | Tab 样式 + 详情面板样式 + 表格样式 |

**不改后端**：所有需要的 API 已存在：
- `GET /macro/dashboard` — 指标列表（含 meta）
- `GET /macro/indicators/{code}?limit=500` — 完整时序
- `GET /macro/views` — 判断快照
- `POST /macro/views/generate` / `/record` — 生成/记录

## 5. 不做的事（YAGNI）

- ❌ 不新增后端 API（现有够用）
- ❌ 不加路由/URL 参数（tab 切换纯 state）
- ❌ 不做指标对比功能（本次只做单指标详情）
- ❌ 不做导出/下载（历史表格够用）
- ❌ 不改 `macro_indicator` API 的 limit 默认值（前端请求时传 limit=500）
