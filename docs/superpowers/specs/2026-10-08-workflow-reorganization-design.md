# 体系化重组：工作流主轴（Workflow-Axis Reorganization）

> 日期：2026-10-08
> 范围：前端信息架构重组 + 工作流串联 + 嵌入式 AI 统一 + 移除 AI 交易助手
> 状态：设计已获用户批准（逐节确认）

---

## 1. 背景与痛点

现状：前端 6 组 28 个菜单项、后端 31 个 router。2026-09-08 开源瘦身曾砍到
5 组 20 项，一个月内又长回 28 项——功能生长快于体系收敛。

用户确认的三个痛点（多选自访谈）：

1. **功能孤立用不上**：部分页面像独立小工具，与"研究→买→持→卖→复盘"主工作流串不起来；
2. **同一件事多处入口**：看市场贵不贵有 指数页 / Thesis 温度卡 / 行业破净率 三个入口；研究一只股要跨 5 页跳转;
3. **AI 能力分散**：AI 助手 / AI 基本面 / 论证库 / 雷达 LLM 分析各自为政。

明确**不是**痛点：菜单项数量本身（"页面太多"未被选中）。

## 2. 决策记录

| 决策点 | 结论 |
|---|---|
| 首要服务对象 | 自用优先、兼容开源（不为新用户让步，但不堵死开源路） |
| 砍功能底线 | 永久组合 / 看板 / 报告 / 自动建组合 **都在用、不砍**；宏观 / 国家队 / 行情 **保留**；唯一砍 **AI 交易助手** |
| 方案选型 | A 主轴重组（六段闭环为信息架构主轴 + 2-3 处实体合并 + 串联机制），否决 B 轻量串联（治标）与 C 全量大合并（单页巨大、打破使用习惯） |
| AI 形态 | 嵌入式统一——AI 是功能不是页面；不做全局对话侧边栏 |

## 3. 目标信息架构

```
开始    开始 · 工作台
市场    ★市场温度(新页) · 宏观政策 · 国家队
研究    选股器 · 财务分析 · 行业分析 · 财报雷达 · 标的对比 · 研究笔记 · 研报 · 行情快照
决策    买入体检 · 自动建组合
持仓    交易 · 持仓体检 · 自选股 · 风险 · 预警
复盘    时光机 · 回测实验室 · 分析 · 看板 · 永久组合
系统    设置 · 系统日志
```

28 项 → 27 项；功能净减仅 AI 交易助手 1 项，其余为迁移/归位（指数页升格为
市场温度页、温度卡与破净率 Tab 迁入，均为 Tab 级合并，不减少菜单项）。

各组语义：

- **市场**：回答"现在贵不贵、该几成仓"——温度/水位/宏观/资金面；
- **研究**：回答"有哪些候选、某只值不值得研究"——筛选拦截 + 深度研究 + 素材沉淀；
- **决策**：回答"买不买、买多少、怎么买"——体检/仓位/建组合；
- **持仓**：回答"拿着时盯什么、怎么执行交易"；
- **复盘**：回答"做得怎么样、怎么验证与改进"。

## 4. 合并动作

### 动作 1：市场温度页（★，"看市场贵不贵"三入口合一）

- 载体：扩展现有 `/indices`（本来就是估值水位主题），菜单更名"市场温度"；
- Tab 结构：
  1. **温度计**：五档温度 + 股债性价比 ERP 与历史分位 + 水位策略回测结论
     （从 `Thesis.tsx` 顶部温度卡抽出为共享组件迁入，含 16 年 ERP 曲线展开）；
  2. **指数水位**：现 `Indices.tsx` 全部内容（指数卡片条 / 列表+图表 / 排行表）；
  3. **破净率择时**：从行业分析页迁移该 Tab；
- `Thesis.tsx` 顶部保留一行精简温度条 + 点击深链到新页——"持仓时瞄一眼"场景不破坏；
- 后端零改动（数据端点均已存在），纯前端重组；
- 行业分析页移除破净率 Tab 后其余 Tab（景气热力图/资金流/RS）保留。

### 动作 2：移除 AI 交易助手

- 删 `pages/AIChat.tsx` + `AIChat.css`、`/ai-workspace/trader` 路由、后端 `ai_chat_router.py`；
- **删前核实**：`ws_router` / 统一收件箱 / LLMManager 等对 ai_chat 的依赖，凡引用处一并清理；
- 后端相关测试同步删除。

### 归位动作（页面不动，仅菜单/文案调整）

- 行情快照：市场组 → 研究组（"看一只股"的轻量入口，语义属研究）；
- 报告、永久组合、自动建组合、看板：保留，按第 3 节归位；
- Dashboard（账户资产）/ 分析（业绩统计）/ 看板（自定义卡片）：**不合并**，开始页场景卡写明三者分工并互链。

## 5. 工作流串联机制

- `config/navigation.ts` 扩展为工作流单一数据源：每个 NavItem 声明
  `stage`（六段之一）+ `prev` / `next`（上下游常用跳转目标）；侧栏（Layout）与开始页（Start）继续共用该文件；
- 每页页头渲染轻量工作流条：`研究 / 财务分析　← 选股器　买入体检 →`，点击直达；
- Thesis 复盘区"研究管道"各层（研究中 / 观察 / 已体检待决策）的股票条目加直达链接（财务分析 / 标的对比 / 买入体检）——管道从"名单"变"入口"；
- 开始页：六段工作流图与场景卡按新结构重排，场景卡补 Dashboard/分析/看板分工说明。

## 6. 嵌入式 AI 统一

- 新建共享 `AiInsightPanel` 组件：统一视觉、加载态、流式/分步渲染、错误与重试态；
- 渐进替换各自为政的 AI 面板：财务页 AI 基本面、论证库、财报雷达 LLM 分析、macro LLM 分析等（逐页替换、逐页验收，不一刀切）；
- 统一走 `llm_config` 配置（glm-dashscope 默认），清理论证库残留的 LLMManager/MiniMax 双路径；
- 不新增任何 AI 页面。

## 7. 明确不做

- 不砍：永久组合、看板、报告、自动建组合、宏观、国家队、行情；
- 不动：后端数据层、17:30/17:35/18:30 等 job、UI 令牌体系、既有数据表；
- 不做全局 AI 对话侧边栏；
- 不动 Dashboard/分析/看板三者边界。

## 9. 验收标准

- 菜单 7 组 27 项（开始+六段主轴市场/研究/决策/持仓/复盘+系统），`/indices` 更名并承载三 Tab 温度页，行业分析页无破净率 Tab；
- 全站无 AIChat 残留引用（前端 grep + 后端 import 检查 + pytest 全过）；
- 每页页头可见工作流条且跳转正确；开始页场景卡全部指向新结构；
- `navigation.ts` 仍是侧栏与开始页的单一数据源（无重复定义）；
- 前端 `vitest` 与后端 `pytest` 全绿。
