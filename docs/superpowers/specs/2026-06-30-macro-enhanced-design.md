# 宏观经济板块 · 增强设计（两段式 AI 意见 + 人机留痕）

> 日期：2026-06-30
> 范围：在现有 `/macro` 板块（已实现 v1）上增量改造，支持"AI 两段式意见（客观解读 + 立场）、人偶尔记录、双轨验证分开打分"。
> 方案：A（在现有结构上增强），不推倒重来。

---

## 1. 背景与目标

### 1.1 现状
项目已有一版宏观板块（v1）并跑通：
- 数据层：`macro_indicator` / `macro_indicator_meta` 表（CPI/PMI/M2/社融/LPR + 美国CPI/非农/失业率）、全球指数（标普/纳指/道指/恒生/国企）、商品（XAU/OIL）、外汇（USDCNY/JPYCNY）均已同步。
- 判断层：`macro_view` 表存 AI 判断快照，`macro_analyst` agent 生成结构化判断（多维度 macro_judgments + 资产预测），prompt 走 DB（`prompt_template` 表，可在 Prompt 控制台编辑）。
- 验证层：双轨 job——宏观立场用宏观数据验证、资产含义用走势验证，分开打分（macro_accuracy / asset_accuracy）。
- 展示层：`/macro` 页面（React/TS，recharts），`/macro/*` 共 7 个 API 端点。

### 1.2 本次改造的目标
v1 的 AI 意见是"一段叙事 + 立场"混在一起，且只有 AI 留痕。用户要求：
1. **AI 意见分两段**：先客观解读（不下结论），再明确立场 + 理由。
2. **立场默认折叠**：让用户先读完客观解读、形成自己的初步看法，再展开对照 AI 立场。
3. **人也能留痕**：用户在重要时点可手动记一笔自己的判断（立场 + 置信度 + 理由），走同一套双轨验证。
4. **人 vs AI 并列回看**：历史对照表区分来源（AI / 我），长期积累出"谁更准"。
5. **指标按国家分组**：中国指标与美国指标分开展示。

### 1.3 非目标（YAGNI）
- 不做人的独立模块/独立视图（人只是偶尔记一笔，共用 macro_view 表 + author 字段）。
- 不重构表结构（现有 macro_view 增量加字段即可，老数据自动兼容）。
- 不做自我进化/拐点雷达/多视角辩论等扩展超能力（本次聚焦核心形态）。

## 3. 数据模型（macro_view 表增量改造）

现有表 + 2 个新字段，老数据自动兼容。

### 3.1 字段变更

| 改动 | 字段 | 类型 | 说明 |
|---|---|---|---|
| **新增** | `author` | `str`, default `'ai'` | 留痕主体：`'ai'` / `'user'`。区分 AI 判断与人记录。老数据默认 `'ai'`（兼容）。 |
| **新增** | `objective_reading` | `str`, default `''` | AI 的**客观解读**文本（不下结论，逐指标解释含义/趋势/关系）。人记录时此字段为空。 |
| 复用 | `summary` | `str` | **语义变更**：从"宏观叙事"改为"立场理由"。AI 的立场理由叙事；人的判断理由。 |
| 保留 | `overall_stance` / `confidence` | — | 立场的结构化摘要（bullish/bearish/neutral + 0-10）。AI 和人都填。 |
| 保留 | `macro_judgments` / `asset_predictions` | JSONB | AI 填（多维度 + 资产方向）；人通常不填（留空，验证时只验证填了的部分）。 |
| 保留 | `macro_validation` / `asset_validation` / `macro_accuracy` / `asset_accuracy` / `status` | — | 验证字段，AI 和人共用，无改动。 |

### 3.2 关键设计点
- **人和 AI 共用一张表、同一套验证机制**：`author` 区分，验证 job（`validate_pending`）已扫描所有 `status=pending`，不分 author → 人记录零额外代码自动进验证队列。
- **老数据兼容**：`author` 默认 `'ai'`、`objective_reading` 默认空字符串，现有 AI 快照不受影响（只是 `objective_reading` 为空，前端老数据不显示客观解读区）。
- **人记录可更轻**：人只填 `overall_stance` + `confidence` + `summary`（理由），`macro_judgments`/`asset_predictions` 可留空。

## 4. AI 两段式意见生成逻辑

### 4.1 生成时机（无改动）
- 定期：每周五收盘后（`macro_snapshot` job，已有）。
- 手动：版面"生成判断快照"按钮（`POST /macro/views/generate`，已有）。

### 4.2 输出结构改造（schema + prompt）

`macro_analyst_node` 的结构化输出 schema（`MacroViewResult`）新增 `objective_reading` 字段：

| 字段 | 内容 | 版面位置 |
|---|---|---|
| `objective_reading` | **客观解读**：逐指标解释"当前值说明什么、趋势方向、与历史/阈值对比、指标间关系"。**禁止结论性判断**（不说偏多/偏空、不说利好/利空）。 | 中部·上半（先看，默认展开） |
| `overall_stance` | 明确立场：bullish / bearish / neutral | 中部·下半（后看，默认折叠） |
| `confidence` | 置信度 0-10 | 立场旁 |
| `summary` | **立场理由**：为什么是这个立场（引用数据点 + 点名理论框架） | 立场下方 |
| `macro_judgments` / `asset_predictions` / `signals` | 保留（多维度判断 + 资产预测 + 指标快照） | 折叠详情 / 验证用 |

### 4.3 Prompt 改造（可编辑）

现有 `macro_analyst_system` / `macro_analyst_user` prompt 模板（存 DB，Prompt 控制台可编辑）改为**强制两段思考**：

1. **第一段指令（客观解读）**：先客观解读下列指标的含义，**不要给出任何结论性判断**（不说"偏多/偏空"，不说"利好/利空"）。只解释：每个指标当前值说明什么、趋势方向、与历史/阈值的对比、指标间的关系。输出到 `objective_reading`。
2. **第二段指令（立场）**：基于上述客观解读，给出你的宏观立场（偏多/偏空/中性）、置信度、理由。输出到 `overall_stance` / `confidence` / `summary`。

用户可在 Prompt 控制台随时调整分析口径，改完下次生成即生效。

## 5. 人的留痕 + 验证机制复用

### 5.1 人记一笔的交互（轻量表单）

AI 意见区下方放"**我记一笔判断**"按钮，点击弹出表单：

- **你的立场**：单选（偏多 / 偏空 / 中性）
- **置信度**：滑块 0-10
- **理由**：文本框（写下判断依据，可长可短）
- 人**不填**客观解读、不填资产预测（那是 AI 的活）

保存 → 存入 `macro_view`，`author='user'`，`snapshot_date`=当天，`status='pending'`。

### 5.2 新增 API

- `POST /macro/views/record` —— 人记录自己的判断。
  - 请求体：`{overall_stance, confidence, summary}`（`summary` 理由为必填，`overall_stance` 必填，`confidence` 可空）
  - 行为：创建一条 `author='user'` 的 macro_view，`status='pending'`，`horizon_days` 取配置默认值。

### 5.3 验证机制（人记录需小幅扩展）
现有 `validate_pending` job 扫描所有 `status=pending` 的快照（不分 author）：
- 人记录到期 → 自动进验证队列 → 双轨打分。

**人的立场怎么验证（关键设计点）：**
人只填 `overall_stance`（偏多/偏空/中性），不填 `macro_judgments` 各维度。现有 `macro_judgments` 验证逻辑不适用于人记录。因此对 `author='user'` 的快照，验证逻辑改为：
- **宏观轨道**：用"代表性指数组合"（沪深300 + 标普500 等权）在预测期内的实际涨跌方向，对照人的 `overall_stance`（偏多→预期涨、偏空→预期跌、中性→震荡）。这是对"人整体立场"的宏观代理验证。
- **资产轨道**：若人没填 `asset_predictions`，则 `asset_accuracy=None`。
- 结果：人记录通常 `status='scored'`（宏观轨道有验证）或 `partial`（仅资产轨道无数据）。

此扩展仅对 `author='user'` 生效，不影响 AI 快照（AI 仍走 `macro_judgments` 维度验证）。

### 5.4 人 vs AI 并列展示

历史对照表新增 **`来源` 列**（author），AI 与人记录混排按日期倒序：
```
日期      来源  象限   立场    宏观命中   资产命中   状态
06-30     AI   复苏   偏多    67%        75%       已验证
06-30     我    —     偏多    100%       —         部分     ← 人记录（宏观用代表指数组合验证）
06-23     AI   复苏   偏多    —          —         待验证
```
长期积累 → 看出"AI 在哪准/人在哪准/共同错误处（往往是拐点）"。

### 6.1 各区块实现细节
- **❶ 指标分组**：前端按 `indicator.category`（`cn`/`us`）分两组渲染，各带小标题（"中国"/"美国"）。卡片点击可弹小窗看历史时序图（`GET /macro/indicators/{code}`，已有）。
- **❷ 两段式**：`objective_reading`（中性强排版、默认展开）与 `summary`/`overall_stance`（强调配色、默认折叠）分两块。老数据（`objective_reading` 为空）只显示立场区。
- **❷ 折叠交互**：立场区用 `<details>` 或 React state 控制，标题显示立场徽章 + 置信度，点击展开理由 + 资产预测。
- **❸ 来源列**：`author` 渲染为"AI"/"我"，便于横向对比。
- **❸ 抽屉**：复用现有 `ViewDetail` 组件（已有 K 线对照、双轨验证详情）。
- **设计 token**：沿用 Apple Dark（与 Indices/Intel 页面一致）。
- **响应式**：移动端指标卡片改 2 列、两段式纵向堆叠、历史表精简列。

## 8. 成功标准
- AI 生成的快照含 `objective_reading`（客观、不下结论）+ 立场两段，prompt 可在 Prompt 控制台编辑。
- 用户可在版面记一笔自己的判断（立场+置信度+理由），存入 macro_view（author='user'）。
- 人记录到期后自动进双轨验证，历史表区分 AI/我并各自显示命中率。
- 指标按中国/美国分组展示。
- 立场默认折叠，客观解读默认展开。
- 老数据（v1 快照）不报错、正常显示（`author='ai'`、无客观解读区）。
