# 「开始」页与导航体系重组设计

日期:2026-09-27
状态:已与用户逐节确认

## 背景与问题

平台现有 5 组 26 项菜单、31 条路由,存在四个结构性可发现性问题:

1. **菜单只有 2 字标签无解释**:"时光机""国家队""永久组合"等黑话标签,新用户无法从菜单推断用途。
2. **幽灵页面**:`/checklist`(买入体检)有路由有完整功能,但侧边栏无入口,只能从 Financial 页头深链发现。
3. **招牌功能埋得深**:五法估值中心(ValuationHub)藏在财务分析页 13 个 Tab 中的"估值" Tab。
4. **落地页错位**:`/` 落到「工作台」(量化账户仪表盘:资金曲线/持仓盈亏),与价值投资工作流"先看市场贵不贵"的心智模型不衔接。

唯一的使用指南 `docs/value-investing-loop.md`(85 行:六层工作流图 + 6 个场景 + 页面速查表 + 口径速记)质量高但在应用外,应用内零 onboarding、零帮助入口。

## 目标用户与决策记录

| 决策点 | 结论 |
|---|---|
| 受众 | 自己用 + 少数朋友(非公开运营),不做角色体系/登录 |
| "小白"定义 | 不熟悉本软件的投资者——做**导航层**引导(功能在哪、怎么串),不教投资概念 |
| 改造边界 | 允许重组(菜单分组、落地页、补幽灵入口都可动),标签文字不变 |
| 方案 | A:工作流首页 + 菜单重组 + 速查指南页(否决 B 交互式 tour:自研 UI 无组件、看完即忘、自用零收益;否决 C 纯命令面板:不解心智模型) |

## 「开始」页(`/start`)设计

纯静态展示页,四段结构,内容全部搬自 `docs/value-investing-loop.md`,零新创作:

1. **一句话定位**:页头——"A股价值投资工作台:从判断市场贵贱到卖出复盘的完整闭环"。
2. **工作流地图**:六张横向流程卡(看市场→选股→买前体检→持有→卖出→复盘),每卡 = 层名 + 一句职责 + 该层页面入口链接。
3. **场景卡**(6 个,原样搬文档"按场景找功能"):看市场贵不贵 / 候选股系统排查 / 决定买了 / 持有期间 / 考虑卖出 / 定期复盘。每卡主按钮直达核心页 + 1-2 个次入口。
4. **页面速查表**:全部页面 × 一句话 × 直达链接,顶部过滤输入框(按名称/描述/别名匹配)。底部可折叠「口径速记」(ROE TTM、upside 等防误读说明)。

## 实现结构

前端 monorepo(apps/web),无后端/数据库改动:

- **新增 `src/config/navigation.ts`——单一数据源**:
  - `NavItem { path, label, desc, aliases?, stage? }`、`NavGroup { id, label, items, defaultOpen }`
  - `scenarios[]`(场景卡数据)、工作流分层映射
  - Layout 菜单与 Start 速查表共用,副标题只维护一份。
- **新增 `pages/Start.tsx`**:复用自研组件(Card/PageHeader 风格),无网络请求。
- **改造 `Layout.tsx`**:navGroups 改读 navigation.ts;展开组渲染副标题;默认展开状态按 NavGroup.defaultOpen。
- **改造 `App.tsx`**:路由提为导出数组 `appRoutes` 再 map 渲染(供测试导入);`/` 重定向改 `/start`。

## 测试(vitest)

- `navigation.test.ts`:
  1. 菜单 path ↔ `appRoutes` 双向校验:每个菜单 path 必须有对应路由;每条页面路由若无菜单入口,必须在显式豁免清单登记(防幽灵页面回归)。
  2. 每个菜单项必有非空 desc。
- `Start.test.tsx`:工作流卡/场景卡/速查表渲染冒烟;卡内链接均指向合法路由。

## 非目标

- 不做交互式 tour、全局命令面板(Cmd+K)、角色/模式切换。
- 不改任何现有页面内部结构与功能。
- 不做概念层投资教育内容。
- `docs/value-investing-loop.md` 保留(仓库文档用),应用内速查表与其内容同源、由 navigation.ts 单点维护。

## 风险

- 菜单重组改变作者本人肌肉记忆——已确认接受;标签文字不变降低影响。
- 侧栏因副标题变长——靠默认折叠非核心组控制。
